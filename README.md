# Tic Tac Toe Game with GUI

This is a simple Tic Tac Toe game implemented using Python and the Tkinter library. The game features an interactive GUI where two players can take turns to play the game. The game ends when one player wins or when the board is full, resulting in a tie.

## Features

- **Two-Player Gameplay**: Players take turns to place "X" and "O" on the board.
- **Graphical User Interface**: The game uses Tkinter to display a grid where players can click on cells to place their marks.
- **Win and Tie Detection**: The game automatically checks for a winner or a tie after every move.
- **Reset Game**: Players can start a new game with a button press.

## Requirements

To run this project, you need the following Python library installed:

- `tkinter`
